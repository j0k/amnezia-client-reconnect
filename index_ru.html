AmneziaVPN Reconnect+Proxy

Личный форк официального клиента AmneziaVPN (апстрим 5.0.1.1) с дополнительными функциями для десктопа на Windows. Изменён только клиент — служба VPN и драйверы штатные.

Устанавливается как AmneziaVPN (то же имя приложения и службы, что у апстрима) — установщик обновит официальный клиент, либо удалите его заранее. Исходники: github.com/j0k/amnezia-client-reconnect

✨ Возможности

🔁 Auto-reconnect watchdog

Раз в N минут пингует список хостов через туннель и переподключается, когда они перестают отвечать. Режим all/any, случайный порядок, кнопка Test у каждого хоста, восстановление при зависании (timeout → пауза → повтор), лог событий с таймстампами. Появился из-за ночных обрывов интернета, которых клиент не замечал.

📖 Настройка и какие хосты пинговать: RU / EN

🔀 Два локальных прокси

Direct — мимо VPN с вашим реальным IP (например matchtv.ru из РФ; «два окна браузера — два IP»). VPN — через туннель, чтобы другой ПК в локальной сети выходил через ваш VPN. SOCKS5 / HTTP / HTTPS (TLS), адрес привязки, логин/пароль, allowlist IP, лог. Запуск Chrome, Edge, Firefox или Yandex Browser через Direct-прокси одной кнопкой Launch — и готовая командная строка для копирования.

🏗 Архитектура со ссылками на код: RU / EN · 🔐 Сертификаты: RU / EN

🧩 Live split-tunneling приложений

Добавляйте и удаляйте приложения при подключённом VPN — без реконнекта. Переиспользован существующий IPC службы; драйвер Windows умеет только исключать.

🎞 Process Recorder

Таймлайн процессов: NEW / EXITED с длительностью работы, время старта, полный путь, перемотка назад, интервал от 0.5 с.

🏠 Индикаторы на главном экране

«Auto-reconnect enabled», «Direct proxy enabled (адрес)» и «Logs» прямо под кнопкой подключения.

🧠 Интерактивный майндмап

Клик по ветке раскрывает её, наведение показывает детали, ↗ открывает документ. Та же карта для My Mind: RU / EN.
