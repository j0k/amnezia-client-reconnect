🔍 What differs from the official client

  1. Auto-reconnect watchdog — pings a host list → automatic reconnect (interval, all/any mode, random order, status, Check now).
  2. Test button under every host (resolved IP, packet loss, RTT).
  3. Stuck-reconnect recovery — abort → pause → retry (timeout / pause in seconds).
  4. Home-screen indicators — auto-reconnect / direct proxy / logs.
  5. Event log — txt with timestamps, 4 checkbox categories.
  6. Live app split-tunneling — no reconnect, page editable while the VPN is up.
  7. Two local proxies — Direct (bypasses the VPN) + VPN (through the tunnel); each with bind address, port, optional login/password, IP allowlist, log; types SOCKS5 / HTTP / HTTPS (TLS) with an auto-generated certificate and export.
  8. Tray — state-coloured icon (green / grey / red) that is visible on a light taskbar, tooltip with the state.
  9. Process Recorder — timeline of processes (NEW / EXITED with run time, expand, full path, time slider).

✨ Features

🔁 Auto-reconnect watchdog

Pings a host list every N minutes through the tunnel and reconnects when they stop answering. All/any mode, random order, per-host Test, stuck-connection recovery (timeout → pause → retry), timestamped event log. Born from nightly internet drops the client never noticed.

📖 Setup & which hosts to ping: EN / RU

🔀 Two local proxies

Direct — bypasses the VPN with your real IP (e.g. matchtv.ru from Russia; “two browser windows, two IPs”). VPN — through the tunnel, so another PC on your LAN can use the VPN exit. SOCKS5 / HTTP / HTTPS (TLS), bind address, login/password, IP allowlist, log. One-click Launch of Chrome, Edge, Firefox or Yandex Browser through the Direct proxy, with the exact command line to copy.

🏗 Architecture with code links: EN / RU · 🔐 Certificates: EN / RU

🧩 Live app split-tunneling

Add or remove apps while connected — no reconnect. Reuses the existing service IPC; Windows driver is exclude-only.

🎞 Process Recorder

Timeline of running processes: NEW / EXITED with run time, start time, full path, scrub back in time, interval down to 0.5 s.

🏠 Home-screen indicators

“Auto-reconnect enabled”, “Direct proxy enabled (address)” and “Logs” right under the connect button.

🧠 Interactive mind map

Click a branch to expand it, hover for details, ↗ opens the document. The same map for My Mind: EN / RU.
